INSIGHT LOCAL — VERSION SIMPLIFIÉE POUR GITHUB SUR IPHONE

Cette version ne contient AUCUN DOSSIER à recréer.

Tous les fichiers sont à la racine du projet :
- index.html
- services.html
- methode.html
- a-propos.html
- contact.html
- mentions-legales.html
- confidentialite.html
- style.css
- site.js
- logo-insight-local.png
- carte-professionnelle.png
- carte-visite.png
- robots.txt
- sitemap.xml

IMPORT SUR GITHUB DEPUIS L'IPHONE :
1. Décompresser le fichier ZIP dans l'application Fichiers.
2. Ouvrir le dépôt GitHub insight-local-site.
3. Choisir l'option d'ajout/import de fichiers.
4. Sélectionner TOUS les fichiers du dossier décompressé.
5. Les importer directement à la racine du dépôt.
6. Vérifier que index.html apparaît directement dans le dépôt.
7. Faire le commit.
8. Aller dans Settings > Pages.
9. Source : Deploy from a branch.
10. Branch : main ; Folder : /(root).
11. Enregistrer et attendre la publication.

IMPORTANT :
Ne pas créer de dossier "assets" ni "images" : cette version est spécialement aplatie pour faciliter l'import depuis l'iPhone.
